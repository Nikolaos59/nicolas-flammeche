# Nicolas Flammèche

Site officiel de Nicolas Flammèche, créateur de bougies artisanales. Le catalogue ne contient que Calambour et Petit Pin, avec leurs photos officielles et l’offre d’ouverture à 25 € au lieu de 30 €.

## Développement

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

## Déploiement Cloudflare Workers

Le site est configuré pour être servi comme application monopage à partir du dossier `dist`.

```sh
npm run deploy
```
